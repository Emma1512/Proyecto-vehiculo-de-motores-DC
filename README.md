# Proyecto-vehiculo-de-motores-DC
Diseñar e implementar un sistema embebido capaz de controlar el movimiento y la velocidad de un vehículo de dos motores DC a partir de la información obtenida por un sensor de proximidad y una entrada analógica. El trabajo integraconceptos de GPIO, conversión analógico-digital, PWM, electrónica de potencia y comunicación serie.
